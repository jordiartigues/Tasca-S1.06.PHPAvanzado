# Tasca S1.06 - PHP Avanzado

Descripción: Ejercicios para practicar conceptos avanzados de PHP, incluyendo formularios, variables superglobales, sesiones, constantes mágicas, métodos mágicos y enumeraciones.

## Tecnologías

- PHP
- XAMPP
- Visual Studio Code

## Instalación

1. Clonar el repositorio:

```text
git clone [https://github.com/jordiartigues/Tasca-S1.06.PHPAvanzado.git]
```

2. Abrir el proyecto con Visual Studio Code.

3. Para ejecutar los ejercicios desde la terminal, entrar en la carpeta del proyecto:

```text
cd Tasca-S1.06.PHPAvanzado
```

4. Entrar en la carpeta de los ejercicios:

```text
cd "Nivell I"
```

5. Ejecutar el segundo ejercicio:

```text
php ejercicio2.php
```

6. Ejecutar el tercer ejercicio:

```text
php ejercicio3.php
```

7. Para ejecutar el primer ejercicio, iniciar Apache desde el panel de control de XAMPP y abrir la siguiente dirección en el navegador:

```text
http://localhost/CURSOPHP/Tasca-S1.06.PHPAvanzado/Nivell%20I/ejercicio1.html
```

## Estructura del proyecto

```text
Tasca-S1.06.PHPAvanzado/
└── Nivell I/
    ├── ejercicio1.html
    ├── ejercicio1.php
    ├── ejercicio2.php
    └── ejercicio3.php
```
